# AIに渡すDBパック 構想メモ

> 社内DBから「ある件に関係する行だけ」を、意味の説明つきで1つのファイルに切り抜き、社内のAI(M365 Copilot など)に添付して調査や説明をしてもらう道具。
> 名前: **kirinuki-db**(2026-10-12 決定。npm の `kirinuki` は使用済み、`kirinuki-db` は空き)

## 1. 前提
- DBは参照権限(SELECT)だけ。設定変更・トリガー・一時テーブルは使わない(ashiato と同じ)
- 社内PCのローカルで動かす。出力ファイルは社内のAI(M365 Copilot)に渡す想定で、社外には出さない
- 対象DBは SQL Server と Oracle を最優先。主要DBに広げられる作りにする(ashiato のアダプターを流用できる)

## 2. 体験イメージ
```
$ kirinuki orders 1042            # 起点のテーブルと主キーを指定
  orders 1件 → order_items 2件 → items 2件 → stock 3件 → customers 1件
  + 周辺の集計: 同じ商品を使う未出荷注文 14件(集計のみ)
  → 1042.xlsx を書き出しました(48KB)
```
できた Excel を Copilot に添付して「この注文の状態と在庫を説明して」と聞く。

## 3. ファイルの中身(Excel が標準)
1. **はじめに**:起点、たどった関係、抜き出した範囲、伏せた項目、「このファイルで分からないこと」
2. **テーブル説明**:テーブルの意味、抜き出した行数と元の行数
3. **列説明**:型、意味、区分値の意味(01=受付 など)、参照先
4. **周辺の集計**:行ごとは入れないが判断に要る数字(同じ商品の未出荷注文の合計数量など)
5. 各テーブルのシート

出力形式は切り替え可能:Excel(Copilot向け)/ SQLite(Claude など向け)/ CSV+Markdown。
M365 Copilot は .db を添付として読めないようなので Excel が標準(添付は1ファイル10MBが目安。大きいときは OneDrive / SharePoint に置く)。

## 4. 試してわかったこと(2026-10-12、架空サンプル [sample-pack.xlsx](sample-pack.xlsx) を Claude に添付)
- 区分値(02=引当済)と列の補足(「在庫は引当済の分を差し引き後」)を正しく使って、状態と在庫を説明できた → **説明書を同じファイルに入れる効果は大きい**
- AI自身が足りない情報を指摘した:どの倉庫から引き当てたか(引当テーブル)、同じ商品を使う他の注文
  → **親をたどるだけでは足りない**。設計に入れること:
  - たどる向きを選べる:親(参照先)は常に / 子(明細など)は指定 / 逆参照(同じ商品を使う他の注文)は件数上限つき、または集計だけ
  - **外部キーが宣言されていない関係の推測**:業務DBでは外部キー制約がないことが多い。列名と値の一致から関係の候補を出し、人が確認して設定ファイルに保存する
  - 「はじめに」に、入っていない範囲を書く(AIが勝手に推測しないように)

## 5. 説明(列の意味・区分値)をどこから集めるか
- DBのコメント(SQL Server の `MS_Description`、Oracle の `ALL_COL_COMMENTS`)があれば使う
- 値の傾向(種類の少ない列は区分値の候補、値の一覧と件数)を自動で集める
- 意味の下書きはAIに書かせ、人が直して **辞書ファイル(YAMLなど)** に保存。一度書けば以後のパックすべてに入る。チームで共有でき、これ自体が「テーブル定義書」になる
- 辞書から Excel のテーブル定義書も出力できる

## 6. 伏せ字(任意)
社内で使うなら必須ではない。必要な現場向けに、列ごとに「仮名に置換(同じ値は同じ仮名)」「一部だけ残す(都道府県のみ)」「削除」を選べるようにする。書き出す前に一覧で確認できる。

## 7. 段取り(案)
| 段階 | 内容 |
|---|---|
| 1 | SQL Server / Oracle:起点指定 → 宣言済み外部キーをたどる → Excel 出力(説明シートつき) |
| 2 | 辞書ファイル(列の意味・区分値)と、値の傾向からの自動下書き |
| 3 | 外部キーのない関係の推測と確認、逆参照の件数上限・集計 |
| 4 | SQLite / CSV 出力、伏せ字、テーブル定義書の出力 |
| 5 | 主要DB対応、ashiato との連携(記録した差分の行をそのままパックにする など) |
